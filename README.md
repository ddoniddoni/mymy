# mymy - 자신이 만든 작품을 공유하고 출시 예정인 제품을 알아볼 수 있는 커뮤니티 플랫폼

mymy는 크리에이터, 개발자, 혁신가를 연결하는 커뮤니티 중심 플랫폼으로, 진정성 있는 제품 출시와 진솔한 피드백이 만나는 활기찬 공간입니다.

---

Link : https://mymy-five.vercel.app/

---
## 🚀 Features

### ⚙️ Technical Foundation

- **Next.js 16** App Router 아키텍처
- **Clerk** 기반의 안전한 인증 (Passkeys, GitHub, Google)
- **NeonDB PostgreSQL** 데이터베이스
- **Drizzle ORM**을 활용한 타입 안전한 DB 연산
- 프로젝트 검수 및 관리를 위한 관리자 페이지
- 보호된 라우트 및 API 엔드포인트

---

### 📦 Project Management

- 상세 정보를 포함한 간편한 프로젝트 등록
- 지능적인 프로젝트 분류 및 태그 시스템
- 추천 프로젝트 하이라이트
- 최근 출시된 프로젝트 피드
- 풍부한 정보를 제공하는 프로젝트 상세 페이지
- 앱, AI 도구, SaaS 제품, 크리에이티브 프로젝트 지원

---

### 🎨 User Experience

- 아름답고 인터랙티브한 제품 카드 및 레이아웃
- 제출한 프로젝트를 관리할 수 있는 대시보드 (admin)
- 모바일 및 데스크톱을 지원하는 반응형 디자인
- 실시간 투표 시스템 (Upvote / Downvote)
- 프로젝트 탐색 및 발견 기능

---

## ⚡ 주요 기능

### 🛠️ 핵심 기술:

- 🚀 Next.js 16 (App Router, SSR, Server Components 기반)

- ⚛️ React 19 (재사용 가능한 컴포넌트를 사용한 인터랙티브 사용자 인터페이스 구축 지원)

- 🎨 ShadcN UI (접근성 및 사용자 정의 가능한 React 컴포넌트 지원)

- 📜 TypeScript (정적 타입 지정 및 향상된 개발 환경 지원)

- 💅 TailwindCSS 4 (유용성 우선의 반응형 스타일링 지원)

- 🔑 Clerk (Passkeys, Github, Google Sign-in을 이용한 안전한 인증)

- 💾 NeonDB (제품 및 사용자 데이터 저장을 위한 서버리스 데이터베이스)

- 🗄️ Drizzle (타입 안전성을 보장하는 데이터베이스 쿼리 및 마이그레이션)
- ✅ Zod (스키마 기반 데이터 검증 및 폼 유효성 처리)

- 🎯 React Hook Form (효율적인 폼 상태 관리)
